# ADR-0004: Make compliance applicability a structured SRS section

The adopted professor brief includes a compliance/control matrix. A security
dimension label alone does not supply that artifact. Add a sequential compliance
specialist after the canonical requirements, before supporting designs.

Each mapping links existing requirements, original evidence and source excerpts,
identifies framework/policy and control, records confirmed/advisory/pending status,
and requires human review. Unknown jurisdiction or frameworks remain explicit
gaps. There is no default banking regulation, certification claim or final legal
determination. The same structured matrix appears in the UI and all exports.
