# ADR-0044: Correct an invalid witness without re-authoring valid test behavior

The native-schema-fixed campus run passed the new introduction, then repeatedly
copied "successful internet access ... without interruption or redirection" as
observable evidence. The source requires internet access, not uninterrupted
availability. Whole-criterion correction kept reproducing the same witness.

If replacing only the witness in a temporary diagnostic clears all criterion
errors, ask the local model for a typed observable-evidence-only correction. Merge
only that field and revalidate the full criterion/requirement. Retain its ID,
GIVEN/WHEN/THEN/method and valid sibling criteria. Never persist the diagnostic
replacement or silently insert an assistant-authored witness after model failure.
General criterion repair remains available for other or multiple defects; its
context should contain the canonical ID/statement, not duplicate test bodies.

The same run's VPN source completion also copied a bad message/log witness into
an otherwise source-backed administrator requirement. Compact the existing-row
context for missing-obligation drafting. If that bounded request exhausts retries
with a typed rejected candidate, permit the same criterion repair followed by
the complete completion gate. Keep the actual normative author and failed-call
count in private failure metadata; never guess authorship or count recovery as
fewer model calls. There is no recursive full-section retry.

A known data-lifecycle counterexample must not be hidden by this optimization:
creating a new log "on day 15 after its creation" does not exercise expiry of an
existing record. Recognize creation-only deletion triggers without an elapsed-time
or retention-processing step as a criterion defect. Check it on canonical and
linked criteria, so fixing logging alone cannot preserve that known invalid WHEN.
Valid record setup plus controlled time/retention processing remains permitted.

Record the repair policy and ordinary model provenance. No source fact, arbitrary
test quota, provider/framework, training label or human approval changes.
