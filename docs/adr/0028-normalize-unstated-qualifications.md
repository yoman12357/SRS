# ADR-0028: Preserve source behavior without unsupported timing or message qualifications

2026-10-28 local time. Frozen profile 1.25 failed campus architecture on model-added
real-time visibility/status guarantees despite explicitly undecided response-time
thresholds. VPN denial-test completion correctly denied a support-operator grant,
but repeatedly required an error message claiming exclusive administrator powers.
The source states the support-operator restriction, not that exclusive policy.

Extend deterministic source normalization, analogous to removing an added minimum
from a bare retention duration. Remove uncommitted positive timing modifiers from
generated architecture prose and proposed node names before endpoint names freeze.
Preserve explicit source timing and negations, keep latency decisions unresolved,
and record the original/normalized fields in private audit history. An undecided
source mention is not a positive timing commitment.

For an otherwise valid attempted source denial, remove an unsupported trailing
explanation/example from the model-authored message and witness. Preserve the
given/action, denial outcome, method and observable artifact. Re-run the complete
permission oracle before accepting the normalized test. Do not rewrite a standalone
exclusive policy, an unexercised/wrong-role action, or a source-explicit exclusive
rule. If the safe edit is unavailable, retain the rejection for model correction.

The existing source/actor/action/citation/relationship gates still apply afterwards.
No new requirement, latency value, test template or human approval is fabricated.
Raw model responses and explicit normalization events remain in the private audit.
This handles observed unsupported qualifications; it is not an entailment proof.
