# ADR-0033: Keep passage-authored linked acceptance within its source

The raw trained-first campus regression at
`data/evaluations/20261028-042259-finetuned` failed functional generation. While
drafting E-007's automation prohibition, base correction repeatedly added an
unrelated FR-002 manual-isolation test with empty evidence and an invented
device-management log. Whole-artifact validation correctly rejected it. The
canonical-row repair path could not repair a linked record it never visits.

For isolated passage generation, constrain linked-acceptance targets to canonical
requirements actually grounded in that passage. Existing IDs/titles are an index,
not permission to author new tests for another source. When no such canonical
target exists, constrain the linked-acceptance collection to empty in the native
decoder schema. Validate this ownership independently after parsing; do not
silently discard generated records. Full reviewed section edits may still add
legitimate source-backed linked records under ordinary validation.

Retain all valid authored criteria. A bounded repair of an invalid linked test
must use that canonical requirement's actual source, freeze its target ID and
preserve valid sibling tests. It must not rewrite the canonical requirement or
borrow source obligations from the current, unrelated passage.

Also replace the requirement prompt's request for a 'visible denial' with an
'observable denied result': evidence of denial need not prescribe a new UI
message. Uninterrupted availability and required message copy are stakeholder
decisions, not harmless wording embellishments.

The same frozen run's VPN checkpoints also converted 250 registered users into
parallel/concurrent access, made 25 supported sessions a rejection cap, prescribed
mutual authentication, and claimed unnamed privacy-regulation compliance. The
final verification attempt invented a numerical target and failed. Extend the
recognized source guards to those actual forms, including qualifiers after the
registered subject. Missing named capabilities must enter the existing additive
completion path, preserving valid earlier rows.

Risk labels also lacked supplied likelihood/impact assessments. Native risk
vocabularies and post-parse source checks retain unknown where no rating was
provided. Explicit source labels remain available; these are not calibrated
estimates. This also rejects inferred impact labels in the assistant-reviewed
examples: they are not exempted to keep a passing demonstration.

Implemented as generation profile 1.27 and source-grounding policy 1.2. An isolated
full suite passed 285 tests before promotion. New raw evaluation remains required.
The change does not adopt the
unreliable same-model critic, change model weights, retrain datasets, or bypass
the current validation gates. Historical content and private attempts remain intact.
