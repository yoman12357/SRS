# ADR-0050: Compile source-linked lifecycle activities from model work groups

The real campus Agile workflow added a captive portal, real-time interface,
bi-weekly cadence, steering committee and broader audit scope. A correct ranking
did not make that workflow valid.

Keep evidence-based ranking. Local Ollama explains the winner and groups canonical
requirement IDs into work units. The coordinator composes that methodology's
process from those groups, exact requirement statements, actual verification IDs
and source feedback/unknowns. Delivery roles are proposed and human gates pending.
No process prose invents product features, timing promises or approval authorities.

Agile/Incremental/Hybrid retain build/test/feedback cycles; Spiral includes risk
review; DevSecOps includes recurring secure delivery review; Waterfall preserves
ordered stages. V-Model includes early plans for all four test levels and explicit
links to later execution. All requirements and actual test cases stay represented.
These are proposed activities, never executed tests, approvals or probabilities.

Public SDLC fields stay compatible. Private provenance distinguishes model
explanation/group choices from deterministic workflow compilation.
Status: implementation and real-output verification in progress.
