# ADR-0009: Draft architecture from canonical requirements, not a framework guide

Real output copied a retrieved Zero Trust guide into a campus access-control
architecture, adding posture engines, PKI and CI/CD that stakeholders had not
requested. Labelling that entire design proposed did not make it a useful minimum
architecture for the stated project.

The architecture specialist sees original scope and canonical requirements,
without unconfirmed compliance guidance or a raw framework guide. It drafts
logical components, boundaries, interfaces and flows. Explicit choices are retained;
otherwise named framework/implementation commitments remain absent. Checks catch
the observed unsupported choices. Retrieval remains active in compliance,
threat/risk and conversation tasks, where its advisory role is explicit. No
sourced claim is retained while silently removing its citation.
