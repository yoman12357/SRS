# ADR-0003: Preserve source scope independently of generated prose

2026-10-27. Real runs omitted explicit exclusions from an otherwise schema-valid
introduction and turned planning context into a product capacity cap.

The coordinator projects explicit original exclusions and recognized project
metadata into the introduction as verbatim source-backed items. Model-authored
summary/items remain intact and undergo the same contradiction checks. This is
deterministic preservation of human input, not a template-generated SRS or a
substitute for a failed requirement agent. It invents no facts, acceptance criteria,
requirements, architecture, lifecycle choice or human approval.

The same exact original passages remain in the evidence register and exports.
Metadata routing is constrained in the analysis generation grammar. Recognized
planning numbers cannot become active/concurrent capacity limits. This does not
prove all natural-language entailment; actual case output still requires review.
