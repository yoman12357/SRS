# ADR-0002: Draft normative behavior before adding external guidance

2026-10-27, accepted as correctness repair within the authorized architecture.
The real fine-tuned Qwen run attached correct-looking evidence IDs to unrelated
zero-trust controls retrieved from the corpus, omitting manual administrator
isolation. Schema-valid links were insufficient. The failed run produced no
successful document version.

Requirement specialists now draft only from original stakeholder evidence.
Retrieved guidance cannot introduce a new confirmed product decision. Architecture
and threat agents may use retrieved guidance for explicitly proposed designs;
citations must be literal source excerpts selected through a constrained grammar.
Manual modes, actor preservation and exclusion polarity receive additional
deterministic checks. Acceptance evidence cannot merely repeat the requirement.

This is not proof of semantic entailment. Review actual generated requirements
against source behavior, then run live regression cases and compare the adapter
with base Qwen. Additional citation alignment must preserve the already-authored
normative content; do not label schema/link coverage as correctness.
