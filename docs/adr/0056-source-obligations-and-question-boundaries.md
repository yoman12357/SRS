# ADR-0056: Preserve independent source obligations and scoped decisions

The four-case review found lost email quarantine/alert obligations, compound rows,
unsupported implementation claims, repeated/unrelated questions, functional
behavior hidden in quality sections and network-zone words displayed as people.

Keep the provider, sequential orchestrator, public Document/evidence schema and
IEEE presentation. Extend compact generation with source-clause obligation slots
for recognizable independent predicates. Preserve original evidence IDs and source
text; minimally normalize subject/modal grammar. The model authors acceptance
criteria against each slot. A required source obligation cannot be replaced by an
acceptance criterion, rationale or retrieved guidance. Keep unrecognized clauses
whole instead of silently discarding them. Preserve source roles, qualifiers and
shared objects when splitting action lists; retain conditional/prohibited clauses
whole when splitting would change their scope.

Business validation checks obligation coverage in canonical statements and rejects
known unsupported implementation/latency/threshold/enrollment claims. Label genuine
quality attributes separately from runtime behavior; cross-category references
keep stable canonical IDs. Proposed logical architecture remains distinct from
confirmed stakeholder obligations.

Normalize generated questions using source-grounded decision topics and semantic
keys, retaining all distinct relevant decisions. Filter unsupported presuppositions
and unrelated guidance-derived topics. Preserve explicit stakeholder unknowns and
skipped decisions. Merge shared decisions once in canonical analysis; presentation
uses that inventory instead of reintroducing copies from linked views. Human edits
and source text are never silently rewritten as model output.

Role recognition excludes network/segment/building/device modifiers from human
user matches. Explicit source actors retain their original permissions. Existing
immutable versions and exact-hash human approval rules remain unchanged. New
versions, tests, live regressions and output review establish this change; passing
tests alone cannot establish correctness of an arbitrary future description.

Generated questions require a recognized source-scoped decision topic; shared
nouns alone are insufficient. Explicit stakeholder unknowns remain authoritative.
This deliberately favors conservative machine-question filtering over inventing
new product concepts from RAG. New domains can need additional topic rules.

Atomic tests use private schemas and field-only corrections, bounded by
`CYBERSRS_ATOMIC_TEST_REPAIR_LIMIT` and the existing section deadline. A repeated
trigger/outcome unlocks those two rejected fields together. Valid sibling slots
remain frozen. Normalization removes only known unsupported timing modifiers or
trailing log side effects, retaining the authored result and auditing originals.
This installation uses a 120-second section allowance; no time/completion SLA is
inferred. Compliance receives all statement/evidence identities without repeated
acceptance-test prose. Verification classifications use a private keyed object,
then project to the unchanged public list schema. A sole scenario criterion
cannot be selected away from its primary flow. Public validators remain active.
