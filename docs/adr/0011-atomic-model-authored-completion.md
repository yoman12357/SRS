# ADR-0011: Repair the missing artifact at its own schema boundary

Repeated live evaluation shows that asking for an entire replacement requirement
can preserve a denial while repeatedly dropping a permitted action or a second
actor's obligation in the same source passage. A compound source is authoritative;
neither a field-level validation success nor a copied source ID establishes coverage.

The existing section specialist now asks the configured local model for a missing
requirement when an original action/metric has been omitted, retaining valid rows.
It asks separately for one acceptance test linked to an existing requirement when
a permission test is missing. Every reply is schema-validated and must close its
specific evidence gap. The assembled section then passes the full existing gate.
Only the orchestration granularity changes: no additional external agent framework,
template-authored requirement, fabricated decision or human approval is introduced.
Retries remain bounded, sequential and subject to the workflow budget.

The primary call checks normative source content first. Known permission and
automatic-prohibition test gaps remain private candidates and are completed with
typed test calls immediately, avoiding repeated whole-requirement generation.
Only a passage that passes the complete normative/test gate is checkpointed for
reuse or shared with downstream specialists. Unconditional automation prohibitions
need an attempted trigger and an observable before/after unchanged-state comparison.
Invalid test content is replaced with model-authored verified test content; valid
criteria and normative siblings are preserved. Statement repair runs before its
replacement tests, so a pre-existing scope error cannot deadlock test completion.
