# ADR-0052: Preserve single-role permission statements verbatim

The campus manual-isolation requirement added a prohibition on changes to other
infrastructure, beyond the user's named exclusion. For one original passage with
one positive role permission (and its optional denial), freeze the canonical
statement to that exact source sentence. The local model still authors metadata,
rationale and acceptance criteria. Compound multi-role/semicolon passages retain
the existing extraction path; this shortcut cannot merge those roles.

Use both native constants and independent callback checks. Rejected scope repair
receives a fresh source statement instead of the bad claim. Do not reinterpret
unknown input. Also reject unprovided authentication-flow obligations and broader
infrastructure exclusions in application-bound prose. Test identities remain
valid fixtures; they do not establish an authentication policy.

Status: implementation and actual-output verification in progress.
