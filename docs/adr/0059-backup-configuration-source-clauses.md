# ADR-0059: Preserve backup/configuration noun phrases and product subjects

Live testing the two new supplied briefs exposed source-compiler defects before
the first generation completed. The agent cancelled that test rather than export
an artifact that treated "restore activities" as a separate administrator command
or "It" as a human role. The cancelled run remains in history and timing evidence.

Recognize define/initiate/submit/track as independent source predicates and keep
shared objects (initiate and monitor backup jobs). Treat the product pronoun It
as the system subject. Protect recognized backup-and-restore activity noun
phrases and log-file/entry noun phrases from predicate conjunction splitting.
Do not generalize a human permission, invent an approval workflow or change any
original quote. Keep authored observable criteria and the complete validation
gates. Version the source and prompt rules to invalidate incompatible checkpoints.

Add exact-brief regressions for both supplied projects and preserve all live
attempts. These are document-only operations: neither the test driver nor the
application performs real backup restores or network configuration changes.
